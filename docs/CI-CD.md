# CI/CD

## Hosting

GitHub Pages (free for public repos), deployed by GitHub Actions. Live URL:
`https://umerasiflhe.github.io/store-ready-checker/`.

## Workflows

| File              | Trigger                                                                      | Jobs                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ci.yml`          | push to any branch, pull_request, `workflow_dispatch`                        | `lint` (ESLint, Swift lint, markdownlint, actionlint, shellcheck, commitlint — Dependabot-signed commits exempt in `commitlint.config.mjs` — doc-link check, git-hooks self-test); `web` (repo check, coverage gate, rules/web-samples freshness, build, size-limit); `e2e` (Playwright across Chromium/Firefox/WebKit and Pixel 7/iPhone 15 profiles, browsers and their apt `.deb`s cached by `.github/actions/setup-playwright`, which the deploy smoke job shares, report uploaded on failure); `swift` (`macos-26`: `swift format lint --strict`, build with `-warnings-as-errors`, `swift test`); `swift-linux` (official `swift:6.3.2-noble` image, best effort, not required); `conformance` (`macos-26`: diffs `storeready` JSON against the TS core on every fixture). Every job has a timeout. |
| `deploy.yml`      | `ci.yml` succeeds on a push to `main`; `workflow_dispatch`                   | `build` (Vite build → `actions/upload-pages-artifact`) → `deploy` (`actions/deploy-pages`) → `smoke` (asserts the CSP `<meta>` is in the served HTML, then runs `e2e/analyze.spec.ts` and `e2e/privacy.spec.ts` on Chromium against the live URL).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `release.yml`     | tag `v*.*.*`                                                                 | `verify tag` (tag = `apps/web` = `ToolInfo.swift` version; `CHANGELOG.md` has the section) → `macOS universal` (arm64 + x86_64) and `Linux x86_64` (static Swift stdlib), each packaged with its resource bundle and smoke-tested from the extracted tarball with the build tree deleted → `publish` (GitHub Release, `SHA256SUMS`, notes from `scripts/changelog-section.ts`).                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `real-builds.yml` | weekly, `workflow_dispatch`, push to `main` touching `fixtures/real-builds/` | `ios` (`macos-26`, Xcode 26: XcodeGen + `xcodebuild archive`, unsigned; ready and deployment-target-12.0 variants; records the real `DTXcode`) and `android` (AGP + NDK r28: ready, 4 KB `max-page-size`, `targetSdk 34` variants) → `check` (TS core and Swift CLI on every artifact: expected verdict/rules and identical reports). Artifacts kept 7 days, never committed.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `rules-watch.yml` | weekly, `workflow_dispatch`, push to `main` touching the lock file or script | `scripts/rules-watch.ts` re-hashes each page in `rules/sources.lock.json`; on drift, opens (or comments on) one `rules-change` issue per page. Never commits — accept a reviewed change with `npx tsx scripts/rules-watch.ts --update`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `codeql.yml`      | pull_request, push to `main`, weekly                                         | CodeQL for JavaScript/TypeScript (`build-mode: none`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

Dependabot (`.github/dependabot.yml`) opens weekly grouped minor/patch updates for npm, the Swift
package, and GitHub Actions.

Every third-party action is pinned to a full commit SHA; every workflow sets least-privilege
`permissions` and a `concurrency` group.

## Required checks

Branch protection on `main` requires `lint`, `web`, `e2e`, `swift`, and
`conformance` to pass, with linear history and squash merges only.

## Versioning

SemVer for the tool, date-based `rulesVersion` (`YYYY.MM.DD`) for rule data bumped whenever
`rules/rules.json` changes, Conventional Commits, `CHANGELOG.md` in Keep a Changelog format.
